# Figma AI prompt — Nafess v2

Paste this into Figma AI (First Draft) inside the file "Nafess v2" (team Nafess).
Run it once per screen if Figma asks for one screen at a time; keep the first block in every run.

---

Design a mobile web app screen (390 wide) for **Nafess**, an anonymous mental-health peer-support community for Algeria.
Members use a nickname and an abstract avatar (shape + colour), never a photo or real name.

Visual direction (new, not the current version): calm and warm, soft and human, not clinical, not a social-media feed.
Generous text size (body 18 px), large touch targets (44 px minimum), rounded cards, lots of breathing room.
Light theme first. No emoji, no stock photos of people, no statistics (use "000" where a number would go),
no phone numbers. Errors and crisis help use a warm terracotta tone, never alarm red.
A "Need help now" crisis button is always visible in the header.

Screens (one per run):

1. **Home** — headline "A place to breathe, with people who understand", Join button, how it works (3 steps),
   community chips (Depression, Anxiety, Panic attacks, Grief, ADHD), two story cards, a safety note.
2. **Community** — community header with Join button and an "Every post reviewed" badge, filter chips
   (Everything / Story / Check-in / Small win), story cards with mood badge (Heavy, Low, Okay, Steady, Light),
   nickname, time, reaction and reply counts.
3. **Story** — mood + type badges, title, author nickname with avatar, a content-note veil ("Show story"),
   reaction buttons (I relate / Sending strength / This helped / Thank you), Save, Copy link, Report,
   replies two levels deep with a reply box.
4. **Write** — community select, type chips, mood picker, prompt chips ("Today I noticed…"), title, story text,
   a warm warning card "This may identify you — we found a phone number", "Add a content note" checkbox,
   draft saved status, Post button.
5. **Sign up step 2 of 3** — progress steps, nickname field with "Available" check, avatar picker
   (8 shapes, 4 colours), age range select, Continue.
6. **Moderation queue** (desktop 1440) — tabs Held content / Reports, a held post card showing
   "Found: a phone number" and "Will be published as: … [removed] …", Approve / Reject buttons, recent decisions panel.

Then make an Arabic (right-to-left) version of screens 1 and 4: mirror the layout, Arabic font, same components.
